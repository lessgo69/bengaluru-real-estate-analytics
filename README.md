# 🏢 Real Estate Property Price Analytics (Bengaluru)

## 📌 Project Overview
This project is developed as part of the **CA4 Capstone Project (5th Sem IBA - Business Analytics)**. It analyzes residential property listings across Bengaluru to uncover key structural and micro-market valuation drivers, providing an interactive decision-support dashboard built with Python and Streamlit.

## 🎯 Business Problem
A real-estate company wants to understand what factors influence property prices. This application analyzes location, built-up area, bedroom configurations (BHK), bathrooms, and balconies to identify pricing patterns and assist buyers, sellers, and developers in making data-backed valuation decisions.

## 📂 Dataset Source
* **Dataset Name:** Bengaluru House Price Data (Public Domain)
* **Source Link:** [Kaggle - Bengaluru House Price Data](https://www.kaggle.com/datasets/amitabhannadurai/bengaluru-house-price-data)
* **Processed Records:** 11,985 cleaned residential property listings (derived from 13,320 raw records).

## 🛠️ Technology Stack
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy, OpenPyXL
* **Data Visualization:** Plotly Express, Matplotlib, Seaborn
* **Web Application Framework:** Streamlit
* **Version Control & Deployment:** GitHub & Streamlit Community Cloud
